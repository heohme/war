# UI fix report

## 1. 设计/走查来源

来源为用户对移动端字体折叠和图片优化程度的反馈，以及线上 667 × 375 首页截图、本地 667 × 375 与 568 × 320 渲染测量。没有 Figma nodeId，现有游戏视觉与交互结构保持不变。

## 2. 目标文件

- `app/globals.css`
- `app/page.tsx`
- `public/assets/weapon-*-thumb.webp`
- `public/assets/battlefield-mobile.webp`

## 3. 实际修改

- 紧凑武器卡从三行压缩信息改为两行：武器名 + 范围/伤害/命中率。
- 移除紧凑模式中重复的角色/特点行，提高名称、分组状态、装备状态和数值字号与对比度。
- 568 × 320 超小屏只展示范围与命中率，伤害和完整描述继续由长按详情承载。
- 新增六张 320 × 320 WebP 武器缩略图，总计 76KB；768 × 768 原图继续用于长按兵装档案。
- 首页卡片、攻击选择和战斗回放使用缩略图，并声明固有尺寸与异步解码。
- 新增 960 × 540、28KB 的移动战场背景；桌面继续使用 1672 × 941 原图。
- 手机首页核心美术下载量由约 508KB 降至约 104KB，减少约 80%。
- 960 × 640 引导图保持不变：尺寸、格式和单页加载策略已经合适，避免二次有损压缩。

## 4. 挂载入口

保留 `Home` 页面原有武器卡、攻击面板、回放角色和兵装详情组件。新增 `WEAPON_THUMB_ART` 只负责小尺寸展示；`WEAPON_ART` 仍挂载在长按详情中。没有新增重复卡片、改变武器顺序或覆盖交互层。

## 5. 验证命令和结果

- 667 × 375：页面滚动高度等于 375px；名称 10.08px，数值 6.88px；伤害可见；缩略图自然尺寸 320 × 320；通过。
- 568 × 320：页面滚动高度等于 320px；数值 7.36px；伤害按策略隐藏；范围与命中率完整；通过。
- 两档均无文字行溢出，武器卡与模式按钮完整处于视口内。
- 六张缩略图均为 320 × 320 WebP；移动背景为 960 × 540 WebP。
- ESLint：通过。
- Node 测试：10/10 通过。
- 生产构建：通过。
- `git diff --check`：通过。
