# UI fix report

## 1. 设计/走查来源

来源为用户对手机横屏首页需要下拉的体验反馈，以及本地浏览器对五档移动横屏尺寸的实际边界测量。没有 Figma nodeId；现有战术游戏视觉和页面模块均保持不变。

## 2. 目标文件

- `app/globals.css`
- 挂载组件保持在 `app/page.tsx`，本轮没有修改组件结构。

## 3. 实际修改

- 将游戏根容器固定为动态视口高度，并关闭页面级滚动与橡皮筋溢出。
- 固定移动 Safari 的横屏文字缩放比例，避免字体自动放大撑高页面。
- 在 500px、370px 和 340px 三档低高度横屏中逐级压缩顶部空间、兵装卡和操作按钮。
- 超紧凑横屏隐藏模式按钮副说明，保留“在线匹配 / 单人测试”主操作。
- 窄横屏将左侧说明限制在自身网格列内并最多展示三行，消除与配置卡重叠。
- 品牌、全局操作和首页内容加入横屏安全区偏移。

## 4. 挂载入口

继续复用 `Home` 页面已有 `.game-shell.home-screen`、`.home-copy`、`.match-card`、`.brand-bar` 和 `.global-actions`。没有新增模块、重复节点或透明交互层；匹配、选武器、长按详情和全局操作接线均未改变。
